# WaveCenter

The hub of the DEO movement, and the original DEO.

Its mission: build a modern alternative to the World Wide Web, and a platform
on which other DEOs can extend that mission or develop new concepts.

It begins as a simple to-do list, grows into a project management tool, and
then into a full project management system with a game layer built into its
substrate. That system is how the project will invite others in and bootstrap
itself.
