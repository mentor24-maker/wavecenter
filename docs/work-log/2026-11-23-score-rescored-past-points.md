## 2026-11-23 — Rescored past points earns its point (#193)

An admin can bring everyone's past points up to what each action is worth
today, from the Admin page ("rescoring"). Doing that used to earn nothing:
Game > Manage listed "Rescored past points" as "Not active yet". Now each
rescore that actually saves earns the admin who ran it one point, and it
shows on their Game > My Points page like any other action.

It counts only when the rescore really changes something. A rescore that
changes nothing saves nothing and earns nothing. The point is an ordinary
line on the ledger, not one of the rescore's correction lines, and the
rescore that earned it never adjusts it. If the point cannot be saved, the
whole rescore is undone with it, so the two always agree.

The action also got its four scores with a reason for each (effort 1,
value 2, rarity 2, farm risk 2). Its points stay at 1 until an admin puts
the formula's value live.
