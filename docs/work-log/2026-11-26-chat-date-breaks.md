## 2026-11-26 — Formatting tweaks to discussion panel on Comm (#214)

A long chat on Comm used to be one unbroken column of messages, each with its own small date, so it was hard to see where one day ended and the next began. Now a thin line with the day written larger and in bold ("Today", "Yesterday", "Tuesday, Nov 24") sits at the start of each day's messages, in Mountain time. Since the line already names the day, each message now shows just its time; hovering the time still shows the full date. The task page's chat panel gets the same lines, because it uses the same message list.
