## 2026-11-26 — Tweaks to discussion panel on Comm (#213)

Dane asked for a cleaner chat on Comm. Before, every message repeated "<name> · <time>", which made a conversation busy to read. Now the messages area has a header row naming the two sides once: the other member on the left and "You" on the right, matching where each side's messages sit. Each message shows only its time, and the time on your own messages is right-aligned so you can find them at a glance.

People who use a screen reader cannot see the header, so each message still tells them who sent it with a hidden "You:" or "<name>:" label.

The chat panel on a task's page shares the same chat, so it got the same cleaner look; it was checked there too.
